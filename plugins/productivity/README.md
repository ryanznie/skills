# Productivity Plugin

This plugin contains skills for systematic learning and rigorous plan review.

Fork note:
- `grill-me` is forked from [mattpocock/skills](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md)

Skills:
- `explain-systematically` creates temporary HTML explainers with a causal story, ELI5, visual map, and interactive glossary, saved under `/tmp` by default.
- `grill-me` pressure-tests plans and designs through focused questions.

The skill body itself stays minimal so the attribution lives with the plugin, not the prompt instructions.
