# Productivity Plugin

This plugin contains skills for systematic learning, rigorous plan review, and ambitious task planning.

Fork note:
- `grill-me` is forked from [mattpocock/skills](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md)
- `be-ambitious` is adapted from [robonuggets/be-ambitious](https://github.com/robonuggets/be-ambitious). Its source article is Felix Rieseberg's [How to be more ambitious](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/); see the [Anthropic blog](https://www.anthropic.com/news).

Skills:
- `explain-systematically` creates temporary HTML explainers with a brief context section before the causal story, an ELI5, visual map, and interactive glossary, saved under `/tmp` by default.
- `be-ambitious` raises a task's goal, standard, or perspective through Altitude, Depth, and Range, then plans and carries out the work when appropriate.
- `grill-me` pressure-tests plans and designs through focused questions.

The upstream attribution is preserved with `be-ambitious`.
