# Changelog

All notable changes to the `calendar-skills` plugin are documented here.

## [0.2.0] - 2026-09-21

### Added

- Added UID- and sequence-aware updates for existing iCalendar invites.
- Added support for in-person locations and Zoom-free calendar updates.
- Added formatted update emails with previous times shown struck through.
- Added a gitignored event log at `skills/ai-scheduler/.event-log.jsonl`.
- Added documentation for creating and updating invites.

### Changed

- New Zoom invites now persist their calendar UID and event metadata after sending.
- Released as `v0.2.0+calendar-skills`.

## [0.1.0]

- Initial calendar-skills plugin release.
